# Privato_Locale — SOLO sul tuo PC, mai su GitHub

Questa cartella è ignorata da git (tutto tranne questo README). Serve a conservare **in locale** analisi private,
copie dei checkpoint e output reali. Il repository GitHub è pubblico: qualunque file qui dentro che venisse
forzato in un commit (`git add -f`) diventerebbe pubblico.

Per copiarci dentro materiale in modo sicuro (dry-run di default, originali intatti, hash verificati):
vedi `docs/TRASH_ARCHIVIAZIONE_LOCALE_RUNBOOK_WINDOWS.md` e `scripts/archive_private_local.py`.
